# دنیای احساس

## فایل‌های پروژه

- index.html: صفحه عمومی کاربران
- admin.html: پنل مدیریت
- styles.css: ظاهر سایت
- script.js: عملکرد سایت
- README.md: راهنما

## اجرا

1. هر چهار فایل HTML و CSS و JS را در یک پوشه قرار بده.
2. فایل index.html را باز کن.
3. برای مدیریت، روی «ورود مدیر» بزن.
4. آهنگ‌ها و محتواهای احساسی را اضافه کن.
