# دنیای احساس 🎵

یک سایت ساده برای نمایش آهنگ‌ها و محتوای احساسی.

## فایل‌ها

- index.html: ساختار صفحه
- styles.css: ظاهر سایت
- script.js: عملکرد سایت
- README.md: راهنمای استفاده

## روش اجرا

1. هر چهار فایل را داخل یک پوشه قرار بده.
2. فایل index.html را با مرورگر باز کن.
3. روی آیکن آدمک کلیک کن.
4. وارد پنل مدیریت شو.
5. آهنگ یا محتوای احساسی اضافه کن.

## امکانات

- نمایش آهنگ‌ها و کاورها
- پخش فایل‌های صوتی
- نمایش متن و تصویر
- نمایش ویدیو و ویس
- افزودن و حذف محتوا
- فعال و غیرفعال کردن بخش‌ها

## هشدار امنیتی

این پروژه نمونه فرانت‌اند است.
اطلاعات در مرورگر ذخیره می‌شوند.
ورود مدیر امن نیست و برای انتشار عمومی باید
احراز هویت سمت سرور پیاده‌سازی شود.
